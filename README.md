# Ambush Pressure Chamber — AP Literature Timed Practice

This package is ready for GitHub Pages.

## Files
- `index.html` — the complete self-contained timed practice
- `.nojekyll` — prevents GitHub Pages from applying Jekyll processing

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and `.nojekyll` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. After GitHub publishes the site, use the Pages URL as the link behind your “Click Here to Enter the Ambush Pressure Chamber” image.

The practice is self-contained; no separate image, CSS, JavaScript, or asset folders are required.
